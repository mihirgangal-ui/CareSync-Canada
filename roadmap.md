# 🗺️ Product Roadmap (2026-2027)

### Phase 1: Enterprise Integration (B2B)
* **EHR Connector:** API hooks for PointClickCare and Epic integration for professional home-care agencies.
* **Shift-Handover Reports:** Automated PDF generation for professional care workers.

### Phase 2: AI & Proactive Care
* **Adherence Scoring:** AI-driven "Risk Factor" scores based on missed medication patterns.
* **Voice-First Interface:** Integration with Alexa/Google Home for seniors with low dexterity.

### Phase 3: Hardware Ecosystem
* **Wearable Sync:** Real-time fall detection via Apple Watch/Fitbit API integration.
* **Smart Pillbox IoT:** Bluetooth connectivity to physical medication dispensers.
